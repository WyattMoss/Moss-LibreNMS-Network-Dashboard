Enter your LibreNMS base URL and API token to pull live device, port, and alert data into this dashboard.

Generate a token in LibreNMS under Settings → API Settings → Manage tokens. This page calls the LibreNMS API directly from your browser, so the LibreNMS server must send CORS headers allowing this origin, or you'll need to proxy requests through your own backend. Credentials are kept only in this browser tab's memory and are not saved anywhere.
